## Goblin Arcade

[Goblin Arcade](https://goblinarcade.com/?utm_source=github&utm_medium=profile&utm_campaign=developer_profile) is a collection of eight short, free browser games from Goblin Originals. The games use AI-assisted coding and visual generation and play directly in a desktop or mobile browser without an account or download.

Start with [Goblin Maze](https://goblinarcade.com/play/goblin-maze?utm_source=github&utm_medium=profile&utm_campaign=developer_profile), a two-minute puzzle with daily and random layouts, three maze sizes, and keyboard, swipe, and on-screen controls.
